# Bluestar & Unilink Webapp 2.0

Clean rebuild project for a mobile-first Bluestar + Unilink live bus webapp.

## Main goal

Build a clean new version that works like:

- Megállóhelyi Menetrend app
- bustimes.org journey / vehicle / route linking

The app must connect:

Search → Stop page → Departure → Journey page → Vehicle page → Map → Route page

## Required features

- Stop search
- Route search
- Live departures
- GTFS timetable data
- BODS / SIRI live vehicle data
- Journey page with all stops
- Route page with directions
- Live vehicle list
- Vehicle information page
- Map with route shapes, stops and live buses
- Favorites
- Mobile-first dark UI
- Large readable text
- Bluestar and Unilink styling
